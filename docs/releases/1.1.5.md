# 犀术IME / XSIME 1.1.5

心有灵犀，落笔见术。

本轮将已合入主线的新品牌交付为各平台的独立安装包。目标版本与公开发布状态分开记录；构建通过不等于商店审核通过或真实桌面验收完成。

## 变化

- 简体中文显示名为 **犀术IME**，繁体中文为 **犀術IME**，英文为 **XSIME**。
- 官网统一为 [xsime.com](https://xsime.com)；macOS、Android、Windows 安装信息及 Linux 包元数据使用该入口。
- macOS 更新器按固定 GitHub 仓库 ID 查询，只接受官方 `scholay/rimes` 与 `scholay/xsime` 地址，保留资产、签名和包身份校验。
- 保留 Bundle ID、applicationId、Windows CLSID/注册表身份、Linux `fcitx5-rimes` 包名、既有安装文件名与用户数据路径。直接升级，不需先卸载或清理词库。
- 保留旧帮助和隐私页面地址、Rime/librime 上游名称及许可信息。

## 版本与发布边界

| 平台 | 目标 | 渠道 |
| --- | --- | --- |
| macOS | 1.1.5，通用 Apple Silicon / Intel 包 | `v1.1.5`，须完成签名、公证与同包安装验收后发布 |
| iOS | 1.1.5（59） | 已独立提交 App Store 与外部 TestFlight 审核；本轮不重建或重复提交 |

iOS 59 已送审的二进制保持冻结，应用内官网入口仍为旧地址，下个 iOS 构建再更新。公安备案和欧盟 DSA 继续搁置。

## 旧版 macOS 升级提示

旧版更新器可能拒绝仓库更名后的重定向。1.1.5 正式发布后，请从 [官方 Releases](https://github.com/scholay/xsime/releases) 手动下载新 PKG 并安装一次；保留 `~/Library/RIMES`，不用卸载或迁移数据。网页/Git 的旧地址继续由 GitHub 重定向，不重新占用旧仓库名。
