发布源为 `main` 提交 `0f018eec5668a8cd633b51134ba234351a17401a`（[PR #127](https://github.com/scholay/rimes/pull/127)）。macOS、iOS、Android、Windows、Linux 统一到 1.1.3；iOS 构建号 56、Android versionCode 17、macOS 构建号 136。发布后合入的本记录和下载文档不改变安装包源标签。

## iOS 追加修复构建

1.1.3（57）追加修复普通输入时隐藏 Buffer 的重复无效图形计算，以及键盘隐藏后的状态动画与图片资源占用。268 项模拟器测试通过（3 项按条件跳过）；1,500 次连续按键未再出现已复现的图形错误。上述结果仅对应当时的验证构建。该构建用于替换尚未上线的 56 号待审包，审核与可安装状态以 Apple 页面为准；原始 56 号记录及其余平台安装包仍按下文保留。间歇卡顿的真机反馈仍待跟进，不据此关闭 issue #112。

## 第三方方案导入

五端设置都有 Rime 方案导入入口，同一份标准 ZIP 无需按平台重打包，也支持带编码的 UTF-8 TXT／TSV。导入先检查、暂存与编译，再由用户启用；失败时保留当前方案。删除已导入包时保留学习数据。具体入口、格式与限制见[跨平台方案导入](../portable-scheme-import.md)。

本轮修复 Apple 平台压缩词典头读取、Android 方案布局的系统 API 兼容，以及 Android／Linux 小文本词库的内存映射问题；Windows 完整安装器增加源码与生产载荷核验，Linux 新增原生 DEB。原始万象 v18.1.1 基础包用于跨平台全拼、九键验收，原包 SHA-256 为 `abd00fd2b4135453e53b81d8ac893301e808fdb52290ea72977714dfc67400a2`。通用范围不包含 `.gram` 模型、宿主专用皮肤或外部原生扩展。
