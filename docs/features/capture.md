# Capsule 捕获、编辑与录屏

本模块覆盖截图、滚动截图、精确选区、标注、美化、截后浮层、贴图、OCR/二维码、临时捕获历史和录屏。保持 RIMES 单进程与 macOS 13 部署目标，不包含 Studio 视频编辑或在线分享。

## 使用

- 从 Capsule 底栏相机或默认 `⌘⇧5` 打开捕获横条；`⌘⇧4` 直接框选。快捷键可在设置中更改；若 macOS 自带截图占用，需先取消对应系统绑定。横条采用仅图标按钮，悬停或辅助功能可读名称。左侧为区域、全屏、窗口、滚动、延时、取字、录屏，右侧为比例、画幅、重设画幅和关闭；Esc 关闭。右键横条可恢复最近关闭卡片、打开已有工程、进入捕获与贴图设置。
- 右侧画幅入口支持先框选、再拖动选区、回车确认截图；固定比例在拖动到屏幕边缘时也保持不变。成功确认后记住比例和尺寸，下次仅在鼠标所在屏幕居中恢复并可拖动。在另一块屏幕开始框选时，旧屏选区和待确认结果立即清除；一次截图任务只保留一个活动选区。重设画幅清除旧尺寸以重新框选；`⌘⇧4` 保留松手截图。
- 标签依次为最近、捕获、笔记、图片、视频、PDF、技能、密码。“最近”是剪贴板历史；“捕获”是临时资产；图片和视频是长期收藏。
- 区域选择支持冻结画面、十字线、像素放大镜、像素/点尺寸、固定尺寸/比例、延时和上次区域。区域与画幅截图先并行取得各屏干净背景，再显示选区蒙层，避免将选区边框拍入冻结背景。准备期间再次按 `⌘⇧5` 可取消；显示选区后 Esc 取消会作废迟到结果。首次授权时不提前覆盖系统授权提示，预检查失败仍由 ScreenCaptureKit 实际检测，不据此拒绝截图。日志分别记录蒙层、内容枚举和各屏画面就绪耗时。
- 窗口截图和窗口录屏使用屏幕上的悬停高亮、单击选择，不再使用窗口下拉列表；显示应用与窗口标题，重叠处优先选择最上层可捕获窗口，桌面空白不可选择，Esc 或右键取消，再按 `⌘⇧5` 也可退出。选择层保留点击命中，面板直接处理取消键；工具条在选择层接管焦点后才关闭。全屏直接捕获。截图与录屏只排除捕获工具自身的界面（横条、选择层、倒计时、结果卡片、录制控制条与菜单栏计时、滚动截图面板）；Buffer、Capsule、Mailbox、设置、剪贴板历史、候选窗、贴图与编辑器保持显示并照常被捕获，窗口选择也可选中它们。录制中途出现的捕获界面（如边录边截图）会随即加入排除。
- 结果卡片悬停后显示中央复制／保存图标，角落为关闭、贴图、编辑（视频为播放）；缩略图可拖出。本版移除卡片收藏、更多和云上传入口。点击复制并成功写入剪贴板后，立即移除该卡片，其余卡片自动补位；复制失败保留卡片，历史列表与编辑器的复制行为不变。移除或关闭浮层保留历史，可恢复最近关闭项。位置、大小、自动关闭在捕获设置中调整。
- 结果堆栈在同一屏幕沿边排列，最新一张靠近底角；刷新内容保留窗口身份、顺序和关闭计时。截图期间与整段录屏期间隐藏（录制中截图也不提前恢复），结束后统一恢复布局；这是捕获时唯一自动隐藏的 RIMES 界面。超出屏幕容量的较旧卡片暂时隐藏，关闭可见卡片后补位；资产仍保留在捕获历史。缩略图按完整图片等比缩放，加载失败显示提示。
- 延时截图显示倒计时，Esc、取消按钮或再次按截图快捷键均可取消；不会留下在后台继续执行的等待任务。若 AppKit 枚举的某个屏幕不可由 ScreenCaptureKit 捕获，仅移除该屏蒙层，其他可捕获屏幕继续工作。
- 锁屏、睡眠、会话失活和安全输入分别门控：任一状态未解除都不恢复内容。保护会取消待截图任务，全部解除后恢复仍存活且原先可见的编辑／贴图／文字窗口及结果堆栈；不复活已关闭窗口，不自动恢复录制。
- 贴图可调整窗口大小、透明度，点击后用方向键移动，Shift 加速；锁定穿透后从捕获设置解锁或关闭所有贴图。锁屏隐藏内容。
- OCR 结果可复制、存笔记或显式送入 Buffer；不会直接向宿主输入框发送。导入的 Buffer 块要求显式投递，即使已有自动上屏偏好也不会由 OCR 导入启动投递。

### 自定义窗口圆角

截图结果卡片、编辑器、贴图及捕获辅助窗口与 Capsule 管理窗口使用透明窗口底板，背景和完整内容树在同一圆角内裁剪，避免浅色系统外观下露出矩形底色。替换内容、调整窗口尺寸或切换主题后仍保留裁剪。Capsule 列表与编辑区域同时裁剪滚动内容；Capsule 底栏、Buffer 和卡片悬停毛玻璃另设可伸缩材质遮罩，避免系统背景材质越过圆角。

捕获横条保留两组之间的透明间隙；全屏选区蒙层覆盖到屏幕四角，不做圆角裁剪。设置、Mailbox 等使用系统标准标题栏的窗口继续由 AppKit 管理外形，不改变焦点、拖动与缩放行为。

### 授权与检测

显式截图通过 ScreenCaptureKit 取得可捕获内容，不再仅因 CoreGraphics 预检查失败就阻断。系统实际拒绝当前进程时，截图入口与「设置 → 系统权限」共用一个授权引导：只显示一个标题、一行短说明和当前步骤的主按钮；按状态从「去开启」切到「打开系统设置」或「继续」，不自动连弹错误或跳转。实际检查失败优先于预检查显示。返回应用只更新预检查提示，不自动截图。只将 ScreenCaptureKit 的 `userDeclined` 归为权限问题，服务失败、超时等保留实际错误。

“已勾选”不保证当前进程立即可用，授权后可能需要重启。临时签名开发版每次重建会改变代码身份，旧授权可能仍显示开启却不再匹配；先检测、保存未完成工作并重启，仍失败时在系统设置移除旧 RIMES、添加当前安装路径。稳定的 Apple Development 签名有助于保留开发授权；应用不修改 TCC 数据库、不自动重置权限或重启。设置页「遇到问题」中的「重置辅助功能…」仅处理辅助功能，并需单独确认，不能用来修复屏幕录制。

找不到应用或从权限列表移除后，可展开引导或「设置 → 系统权限」的「遇到问题」，从应用卡片中拖动 RIMES 图标到列表。卡片传递当前运行 `.app` 的真实文件 URL，只允许复制语义，不移动或删除输入法；不从 Spotlight 猜测另一份同名应用。也可点「在 Finder 中显示」选中应用，或「复制路径」，在系统权限列表点「＋」后按 `⇧⌘G` 粘贴定位；应用仍留在 Input Methods 安装目录，不必搬到 Applications。手动添加仅面向屏幕录制、辅助功能和输入监控，摄像头与麦克风仍须显式请求。应用不存在或裸 SwiftPM 调试进程不提供可操作的应用卡片。展开帮助时以卡片的一行操作提示替换原说明，不叠加步骤段落；路径、签名和错误详情保留在工具提示中。基本打字无需这些权限，设置页不要求新用户逐项开启。

录屏只为启用的摄像头、非 GIF 麦克风和全局按键显示请求额外权限，等待用户回答后才能继续。关闭授权引导或进入会话保护会作废在途回调。查看历史、编辑已有截图和贴图不要求屏幕权限。

## 编辑工程

编辑器采用独立深色原生窗口，保留系统红黄绿按钮。顶部单排胶囊工具，中央为完整画布；底部只保留缩放、撤销／重做、拖出图片、效果预览、贴图和复制。删除常驻左右侧栏、底部历史栏和重复保存入口；历史仍在 Capsule 的“捕获”中，不删除任何资产。

可见工具包括裁剪、选择、空心／实心矩形、椭圆、线条、箭头、文字、像素化、聚光灯、编号、画笔和文字高亮。弯箭头、模糊等旧工程数据仍可渲染，本版不再占用工具栏。选择工具可移动标注和图层、双击编辑文字，Delete 删除。可导入／拖入图片；撤销重做支持按钮、⌘Z／⌘⇧Z。缩放支持适合、50%、100%、200%，放大时滚动平移画布。

仅点选或零位移不会新增撤销步骤，也不会清除重做；一次连续拖动作为一个撤销步骤。历史时长对非法、非有限或溢出元数据防御处理，避免损坏的录屏影响整个历史栏。

标注颜色使用弹出色板：饱和度／亮度、色相、透明度、Hex、RGBA、屏幕取色和十个自存色。六位 RGB 工程兼容保留，带透明度的新颜色写为八位 RGBA；透明度会与高亮效果相乘。选中标注可改色和线宽，一次色板调整合并为一个撤销步骤。背景与画布收进顶部按钮弹出层，提供纯色、留白、圆角、阴影、旋转和翻转；旧工程的其他效果不主动清除。眼睛按钮切换标注原始画布／最终效果。

⌘S 保存工程；“完成”保存后关闭，“另存为…”导出 PNG／JPEG。已收藏资产更新原条目，未收藏资产保持临时历史。复制、导出和拖出均使用当前渲染结果，包括未保存的遮盖。旧 `.rimesproject` 仍可从横条右键菜单打开；本版不在编辑器显示工程导出、收藏或云上传按钮。

## 滚动与录屏

滚动捕获支持横向、纵向及手动/自动滚动，显示累积拼接预览。自动滚动单独要求辅助功能授权。匹配忽略边缘固定区域、细化到原始像素，并去除可识别的固定尾栏重复。空白、重复或无法可靠对齐的内容会暂停，保留现有部分并标记未完成。上限为最长边 32,768 像素和总计 6,400 万像素；虚拟列表或动态页面可能需要分段捕获。

录屏可选择区域、窗口或全屏，倒计时、暂停/继续，MP4/H.264 或 GIF；提供画质、帧率、分辨率、光标、系统声、麦克风、摄像头、点击和按键样式选项。初始为 MP4、1080p 上限、30 FPS；系统声、麦克风、摄像头、点击和按键均关闭，后续记住选择。双音源输出混合为一条音轨。摄像头可设置位置、大小、形状及全屏。

GIF 明确不含音轨，转码限制为 2 分钟、15 FPS 和 1280 像素，超限保留 MP4 并提示。录后仅播放/保存/拖出/收藏。MP4 和 GIF 录制均收入视频收藏，不参与 iCloud 同步。

桌面清理通过窗口过滤与纯色合成，不修改 Finder 设置。勿扰联动运行用户填写的系统快捷指令，设置按钮打开 Shortcuts。未配置时不改变系统专注状态。

屏幕、麦克风、摄像头权限只在使用时请求；全局按键显示单独检查输入监控及辅助功能。拒绝授权时提示关闭对应选项继续。保护输入暂停录制并清除按键显示；锁屏、睡眠和会话退出停止采集并尝试封装。设备断开、编码失败会尝试保留片段并标记未完成。

## 资产与同步

默认目录是 Capsule 本地根目录下的 `captures/`。SQLite 只保存索引，UUID 子目录包含不可变原图/视频、版本化工程、当前渲染和原子恢复清单。写入媒体和工程完成后才发布记录；启动时从清单修复索引、回收删除事务，并恢复可播放的未完成 MP4。不完整 MP4 保留原件，不假装恢复成功。

临时历史保留 30 天、最多 10 GB，清理最早未收藏且无使用租约的资产；编辑、浮层、贴图、文件导出和文件承诺拖拽有租约。收藏与历史共享资产身份，重复收藏不复制媒体。现有 Markdown 和旧图片路径继续可读。

图片同步使用现有开关和容量限制，先写图片及自包含工程依赖，再发布条目；依赖不完整会延后或报错。工程原始素材上限 180 MB，归档上限 256 MB。视频没有同步开关。

## 验证与维护

产品构建与自动测试按[维护规范](../development/maintenance.md)在远端 CI 执行。捕获相关 smoke 入口在 [main.swift](../../Sources/RimeBuffer/main.swift)，实现和隔离检查位于 [Capture](../../Sources/RimeBuffer/Capture/)。

回归应覆盖原图不可变、编辑撤销与重做、采集取消、迟到回调、复制失败保留、权限拒绝与重试、保护输入和多屏坐标。混合缩放、不同 Space、真实滚动内容、录屏设备、权限撤销、锁屏睡眠及宿主粘贴还需要实际设备验收。

截图与原始日志保存在本地或 CI 附件中，不提交到 Git。安装或重启输入法按维护规范单独执行，不作为文档或静态检查的默认步骤。
