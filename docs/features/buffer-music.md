# Buffer 电音演奏（0.2.3）

在 Buffer 插件选择器选择「电音演奏」。音乐面板获得键盘焦点后即可演奏，不要求当前输入法为 RIMES。原来的 Buffer 文字保留，音乐模式不自动投递文字。切到其他应用、关闭面板、切换插件或进入锁屏/安全输入状态会停止发声并清除临时 Loop；点击面板可再次演奏。

## 四弦、每排十键

采用标准四弦贝斯的相对指板排列；音色仍是电子合成器。每排第一个键是空弦，其后每键升一个半音，覆盖空弦至第 9 品；相邻弦相差五个半音。

| 界面从上到下 | 物理键位 | 默认音域 |
| --- | --- | --- |
| 1 弦 | `1234567890` | G2–E3（MIDI 43–52） |
| 2 弦 | `QWERTYUIOP` | D2–B2（38–47） |
| 3 弦 | `ASDFGHJKL;` | A1–F♯2（33–42） |
| 4 弦 | `ZXCVBNM,./` | E1–C♯2（28–37） |

按物理位置识别，不依赖输入法字符。键帽 `< > ?` 对应 `, . /`，不必按 Shift。`- = [ ] '` 和右 Shift 均不演奏音符。界面闲置按键不显示键名，按下后显示相对当前调性的唱名；左侧弦号与空弦音名常显。右侧显示调性、大小调选择和当前实时按键构成的和弦（含转位与级数），不把 Loop 的回放音符误作手指按键。默认 C 大调用于和声分析，与 E–A–D–G 的物理定弦相互独立；切换调式改变唱名/和声解释，不强制量化音高。

多键可同时发声。同音不同弦的按键分别持有发声权，松开其中一个不会切断仍按住的另一个。每次按下锁定音高，移调后松开仍释放原音。普通电脑键盘没有压力数据，不伪称提供真实力度感应。

## 控制

| 操作 | 行为 |
| --- | --- |
| 工具栏「移调」步进器 | 每步降低/升高一个半音，不分配快捷键 |
| 工具栏「八度」步进器 | 每步降低/升高一个八度，不分配快捷键 |
| `Cmd+Shift+↑ / ↓` | 上一个/下一个 Buffer 插件，沿用可自定义快捷键设置 |
| `Enter` | 开关架子鼓节拍器 |
| `Tab` | 添加 Loop 轨；再按完成，最多两轨 |
| 短按 `Space` | 轮换八种加花 |
| 长按 `Space`（350 ms 起） | 保持过渡，松开后在小节边界收尾并进入 A/B 下一段 |
| `Esc` 或工具栏停止 | 停止所有音符、鼓点并清除 Loop，面板保持打开 |

工具栏提供 Loop 录制、停止、移调与八度步进器、状态。第二排显示节拍块、A/B 段、BPM、拍型、节奏型及鼓组开关。支持 3/4、4/4、6/8 拍、40–240 BPM，以及 Rock、Funk、Shuffle、Half-time。BPM 统一按四分音符计速；6/8 显示六个八分音符位置，第 1、4 位分组重音。录制或循环中锁定 BPM/拍号，先停止再调整；节奏型可切换。

任何方向键组合均不用于音乐移调。音乐面板获焦时也通过现有快捷键规则执行 Buffer 插件切换；其他 Cmd/Ctrl/Option 快捷键交回 AppKit。BPM 编辑框独立接收数字和方向键，不触发演奏。

## 两轨 Loop

第一轨从 Tab 开始录制，再按 Tab 向上补齐整小节，保留尾部空白并在边界开始循环。第一轨确定全局循环长度。第二轨在下一循环边界开始，长度对齐第一轨；可提前 Tab 完成并补齐，或录满一个周期自动完成。正在等待/录制时也显示对应轨道行。第三次加轨不覆盖已有录音。

每轨有真实录制事件分布、播放游标、静音和删除；两轨独立持有音符，删除/静音其中一轨不切断另一轨或实时演奏的同音。手动加花参与录制，常规伴奏由独立鼓组时钟产生，普通叠录不会重复录入伴奏。最长 16 小节、每次录制最多 8192 事件。当前只保存在内存，不导出文件、不自动量化演奏音符。

## 真鼓组与加花来源

鼓声使用完整、未改动的 **AVL Drumkits Black Pearl 4pc** SoundFont，由 Glen MacArthur 与 Robin Gareus 制作，包含 26 种鼓/打击乐奏法和五层力度采样。包含底鼓、军鼓及边击、开闭/脚踩镲、通鼓、吊镲、叮叮镲及镲帽、铃鼓、牛铃等。不同鼓件直接使用该音源的 MIDI 映射；不是振荡器或噪声模拟鼓。

音源随安装包提供，约 18.5 MiB，不需联网下载。AudioKit 5.7.2 的 AppleSampler 加载音源，主奏电音仍由本地原创音色生成。采样按 CC BY-SA 3.0 及作者的音乐作品例外分发；作者、许可、固定上游版本、原始 README 与 SHA-256 均随包保存。未链接 x42 LV2 或 FluidSynth 代码。

- [AVL 官方鼓组说明](https://www.x42-plugins.com/x42/x42-avldrums)
- [固定版本原始音源与许可](https://github.com/x42/avldrums.lv2/tree/9389f16f139410d9a55f9006976bd54cbd8b7806/sf2)
- [BeatBuddy 官方手册入口](https://forum.singularsound.com/t/official-beatbuddy-manuals/31483)

参考 BeatBuddy 的短按加花、长按过渡、松开在小节末切段的控制方式，自行编写八种加花，不复制其音频或 MIDI：幽灵切分、军鼓双击、通鼓下行、三连推进、底鼓对答、镲片点缀、反拍重音、渐强收束。加入弱音、双击间隔、三连音及渐强。小节后 25% 才触发时排到下一小节；过渡尾部只打一份底鼓/吊镲重音，避免伴奏重复击打。这是有限的原创节奏库，不宣称复刻 BeatBuddy 全部功能。

## 验证与边界

音频准备、MIDI 事件与单调时钟排程运行在专用串行队列，主线程只处理归属和 UI。Loop 时间线分布缓存，避免节拍队列每次扫描整轨。普通 note-off 保留释音，停止清除音符与混响。延迟调度跳过过期瞬态，不补放成一串突发鼓点。

命令：`buffer-music-smoke` 验证 40 键、同音归属、两轨、快捷键、加花和生命周期；`buffer-music-audio-smoke` 用真实 AudioKit 离线渲染 26 种鼓奏法的五个力度区及主奏、释音、限幅和停止；`buffer-music-view-smoke [preview.png]` 与 `buffer-music-panel-smoke [preview.png]` 渲染 520/760/1040pt、0/1/2 轨，并检查实际 Buffer 面板及被动模式还原。Smoke 使用隔离数据根，不操作用户词库。离线出声和程序化输入验证不等于真人试弹或对音色审美的确认。

0.2.1 修复：音乐主体挂在普通容器，避免 NSStackView 在可见窗口录制/增减轨时把它挤到右边。音频引擎每次重启或设备恢复后重新装载指定电音和 Black Pearl 音源。关闭鼓组会取消待发/正在进行的加花、过渡和鼓尾音，也屏蔽 Loop 内录下的鼓事件，但不停止旋律 Loop。关闭后持续按住旧 Space 不会自动重启；新按一次 Space 会明确打开鼓组并加花，开关同步显示开启。

动态窗口回归：设置 `RB_MUSIC_VISIBLE_SMOKE=1` 运行 `buffer-music-panel-smoke [preview.png]`，会短暂显示隔离测试窗口并发出测试音，用真实录制状态经过 0→1→2→1→0 轨，保存 WindowServer 截图（需已有屏幕录制权限）。普通 CI 仍用无声、不显示窗口的检查。

0.2.2：移调/八度仅由工具栏步进器控制；移除音乐对 Cmd+Shift+方向键的移调处理。音乐面板与原有输入法路径共用插件切换快捷键配置，上下方向分别选上一个/下一个插件。

0.2.3：可见 Buffer 的插件导航不再依赖文字捕获租约；退出音乐后，即使捕获暂停，仍可连续切换 Default 和全部已启用插件。文字输入和投递继续使用原精确焦点权限。回归验证连续双向各三圈，不在每次按键前重置插件。
