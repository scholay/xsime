# 摩斯电码（0.1.0）

在 Buffer 插件选择器选择「摩斯电码」。Buffer 接管当前输入框时，空格键就是电键：

| 操作 | 结果 |
| --- | --- |
| 短按空格 | 点（·） |
| 长按空格（超过所选速度的划阈值） | 划（−） |
| 停顿 | 待组合的点划变成一个字母 |
| 更长的停顿 | 结束当前单词，下一个字母开始新单词（自动加空格） |
| `Delete` | 先删最后一个待组合的点划，再删最后一个字母 |
| 连续八个点 | 操作员纠错信号：删除一个字母 |
| `Return` | 立即提交待组合字母与当前单词，并按 Buffer 常规发送 |

其他字母、数字键在摩斯模式下被吞掉，不会进入隐藏的原文轨；`Return`、`Esc`、`Tab`、方向键与各类快捷键保持 Buffer 原有行为。

## 界面

- **上方输入栏**：左侧为映射槽（当前点划对应的字母；无法再组成任何字符时显示 `?`，刚被拒绝的电码显示 `✕`）与待组合槽（已输入的点划）；右侧为从左到右匀速走动的线，每次按键画在发生的位置，字母提交处有细刻度，线走到右端后回到左侧覆盖最旧的记录；最右是按键状态灯，按下时亮起，超过划阈值变色。
- **下方输出位**：解码后的英文，每个单词一个块；已结束的单词可以单独发送，正在拍发的单词在停顿或 `Return` 后才可发送。

## 字符与速度

仅英文：A–Z（大写输出）、0–9，以及 ITU 常用标点 `. , ? ' ! / ( ) & : ; = + - _ " $ @`。工具栏可选速度：

| 速度 | 划阈值 | 字母间隔 | 单词间隔 |
| --- | --- | --- | --- |
| 慢速 | 280 ms | 750 ms | 1.9 s |
| 标准（默认） | 200 ms | 480 ms | 1.25 s |
| 快速 | 150 ms | 320 ms | 0.85 s |

## 声音

按住空格时播放 680 Hz 正弦侧音（5 ms 起止渐变，无爆音）；每解出一个字母有一声短促高音，无法识别的电码是一声低音。音频引擎在第一次按键时才启动，静默 20 秒、切换插件或进入保护状态时关闭，不长期占用音频设备。

## 验证

`morse-smoke`（已加入 CI）用合成时钟验证字母表、点划与停顿判定、单词与发送、删除与纠错信号、吞键规则、保护与切换插件、离线渲染侧音与提示音电平，以及输入栏在真实 Buffer 轨道中的布局；传入路径可输出输入栏与整条轨道的预览图。离线出声与程序化按键不等于真人拍发手感的确认。
