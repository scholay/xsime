# Linux 打字测速与文章练习

打开 **设置 → 内置扩展 → 打字测速 → 文章练习**，选择中英文文章，点击“开始跟打”，第一枚有效按键或预编辑触发计时。输入区使用原生 GTK/Fcitx 文本编辑，拼音预编辑不参与字准；只有已成文内容参与对齐。可主动结束并保存部分成绩，同篇重练保留独立记录。切换文章、输入方案、键位配置、失焦或关闭页面会结束当前练习并标注原因。

## 计分与历史

8 篇文章、版本和计分口径来自当前 macOS 产品。中文显示正确成文字符/分钟，英文显示 WPM（正确字符数除以 5）；物理键、按住重复、删除、编辑回退、组合串回退、更正和已结算并击分别计数。计时连续进行，停顿不扣除；marked text 不作为错误。输入区不接受粘贴、拖放或中键插入，尝试辅助输入会使本次成绩不可比较。

“成绩历史”按文章版本、输入源、方案和键位版本分组，只有完整且未中断的成绩参与比较。不具备并击观测能力时显示“—”，不填零。输入状态服务不可用时仍可练习，但本次不计为可比较成绩；该状态不会阻塞普通输入。

实际 Fcitx 服务仅在明确开始后观察当前设置窗口中的输入上下文，令牌绑定 D-Bus 调用方及该输入区。每 250 ms 读取一次，离开、保护输入、禁用插件或配置变化会撤销采集，客户端意外退出后最多 3 秒失效。它不申请 Buffer 投递权限，不收取输入正文、候选或其他窗口内容。此处的按键与成文不进入日常统计。

## 保存与清理

成绩保存到 `${XDG_DATA_HOME:-$HOME/.local/share}/rimes/stats/typing_tests.json`；`RIMES_USER_DIR` 仅用于指定隔离根目录。文件兼容原生 version 1，仅含文章身份、冻结的输入配置、聚合计数及最多 120 个速度样本，不保存跟打正文或逐键记录。最多保留 500 次、4 MiB，超限时优先保留最新成绩；目录 `0700`、文件 `0600`，后台线程原子写入，关闭页面前排空已接收的保存请求。

损坏、外部改动、过大文件或符号链接会进入只读状态。“备份并重建…”经确认后保留原路径条目并创建空库，不跟随符号链接。“清空成绩…”只影响文章练习，词库、学习记录、日常统计和 CLI 凭据保持不变。卸载 deb 或运行源码 `uninstall.sh` 均保留这些数据。

推荐从项目同一 `v*` Release 安装 deb，安装及卸载命令见 [Linux 安装说明](../ime/README.md)。真实宿主与像素检查见 [桌面验收](../../../docs/platforms/linux/acceptance.md#extensions)。
