# Linux 日常输入统计

在 **设置 → 插件 → 内置扩展** 中开启“统计”，再打开 **统计 → 每日 / 历史**。首次加入 Linux 的统计扩展保持关闭；打开统计页不会开启采集。页底“按键分布”和“输入趋势”独立保存，关闭其中一个不会清空历史或开启另一个。

## 指标与交互

| 指标 | 与当前 macOS 一致的口径 |
| --- | --- |
| 键盘分布 | RIMES 聚焦输入路径收到的物理按键标识和次数，包含重复与快捷键；不监听其他输入法的全局键盘 |
| 输入按键 | 排除按住重复、Control/Alt/Super 等快捷键及纯导航键；保留 Shift 输入 |
| 成文字数 | Rime 上屏或进入 Buffer 时的扩展字素簇数量；缓存再次发送、AI 和翻译派生输出不重复计数 |
| 并击次数 | 已成功结算的物理批次；覆盖飞耀计时结算与呦呦原生松键，排除取消和内部重放 |
| 活跃时长 | 同一会话中相邻有效事件的时间间隔；超过 10 秒、日期变化、时钟倒退及显式边界开始新会话 |
| 日常速度 | 成文字符 × 60 ÷ max(1 秒, 活跃秒数)；没有有效时长时显示“—” |

没有记录的日期保留为未知，不把缺测补成零速度。趋势提供 7 / 30 天和成文字数 / 日常速度切换；点击图表或用方向键选择详情时，不移动趋势日期范围。历史日历可滚动到全部记录并选日；最近会话曲线显示最近 20 次，近期最佳从最近 100 次有效会话计算。键帽悬停显示次数与比例，并提供键盘导航和辅助功能描述。

保护字段、锁屏和受保护会话不会采集。XSIME 设置、文章练习、Buffer 编辑器等自有窗口的输入不进入日常统计；第 28 项另行维护文章测速成绩。正常输入线程只提交脱敏事件，聚合和文件写入在独立后台线程完成。统计或界面不可用不会改变普通输入和投递路径。

## 保存、导出与清理

数据位于 `${XDG_DATA_HOME:-$HOME/.local/share}/rimes`；测试使用隔离的 `RIMES_USER_DIR`。文件兼容 macOS version 1 聚合结构，不含输入正文、逐键时间序列、应用身份、方案名或凭据。

| 路径 | 内容 |
| --- | --- |
| `stats/key_frequency.json` | 按日与标准键标识累计的次数 |
| `stats/typing_speed.json` | 按日字数、按键、并击、活跃时间和最多 500 次聚合会话 |
| `configuration/preferences.json` | 两个独立采集开关，位于 `plugins.builtin.statistics` |
| `stats/corrupt-<随机标识>-<原文件名>` | 用户明确选择重建前保留的原始损坏文件或链接 |

目录权限为 `0700`，文件和导出文件为 `0600`。单份统计文件上限 4 MiB；日期、数量、累计跨度和会话数均校验。一个后台写入者持有排他锁；界面读取、删除与重建经过同一队列。输入法未运行时，页面可以查看历史，并在获得排他锁后执行明确请求的清理。外部修改、损坏、过大文件和符号链接进入只读状态，不自动覆盖；“备份并重建…”保留原路径条目，符号链接目标不会被读取或更改。

“导出…”只导出两份聚合，不包含设置和诊断信息。“清空当天键频…”只影响当前选中日期的键频；“清空键频历史…”与“清空输入趋势…”互相独立，均需确认。词库、输入学习、笔记及文章测速成绩不受影响。

推荐从项目同一 `v*` Release 安装 `fcitx5-rimes_<version>_<arch>.deb`，使用 `sudo apt remove fcitx5-rimes` 卸载。源码安装使用同目录的 `ime/scripts/uninstall.sh`；两种卸载都保留这些用户数据。完整安装说明见 [Linux IME README](../ime/README.md)，真实宿主与视觉检查见 [桌面验收](../../../docs/platforms/linux/acceptance.md#extensions)。
