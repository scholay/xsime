# Capsule 捕获验证（2026-10-18）

对应 #166。截图、静音录屏与私有归档已实现；完整桌面录屏、更多捕获交互及像素对齐仍需验收，任务保持打开。

## 实现与边界

- 独立 `rimes-capsule-capture` 在用户明确操作后启动。X11 使用 GStreamer ximagesrc；Wayland 截图使用 libportal，录屏直接调用 ScreenCast portal，再以授权 Unix FD / PipeWire serial 读取画面。录屏不依赖 RemoteDesktop，也不请求键鼠注入、声音或摄像头。
- PNG 和静音 VP8 WebM，10 分钟 / 1 GiB 上限。编码进程限制内存、文件大小及等待时间；stdin 断开、取消、锁屏信号、会话撤回和插件撤权取消任务并释放会话、管线与文件。停止等待 EOS 后保存。
- 私有归档先流式复制、校验 PNG/WebM 签名和 SHA-256、fsync，再按仍有效的授权原子发布；复制阶段不占归档锁，提交与收藏/删除采用一致的锁顺序。单条损坏索引不影响其他记录；撤权或取消后的结果不得发布。
- 按记录 ID 和修订执行预览、复制、收藏、删除。收藏持久化为 Capsule 条目，清理同时检查稳定收藏 ID、内容引用及媒体租约。删除或 30 天 / 10 GiB 临时清理跳过正在预览/复制的媒体，剪贴板失去所有权才释放租约。
- Linux schema-v1 使用 Unix 时间及每项 JSON；macOS 使用不同的日期编码和存储布局。没有声明二进制/目录直拷兼容；备份和恢复整个 Linux Capsule 目录已验证。
- 原生生产 `CaptureHistoryCard` 和 `CaptureDuration` 导出卡片文字/时长样例，Linux 使用同一份样例并检查 Swift 源摘要。卡片尺寸 206×126、缩略图 186×72、标题前 25 个字符、来源/收藏/时长文字随原生实现验证。

## 已验证

环境为 Ubuntu 24.04 arm64、Fcitx 5.1.7、GTK 3.24、GStreamer 1.24、libportal 0.7.1、PipeWire 1.0.5、Sway 1.9；容器使用无 DRM 的 headless Pixman。macOS 使用原生 debug 构建及隔离导出入口，没有安装或重启本机输入法。

- 归档测试：权限、来源文件独立性、备份迁移后的收藏保护、修订冲突、临时清理、持有租约、取消/授权提交边界、符号链接、非有限时间及损坏记录。
- X11 实际 800×600 PNG、WebM 解码、停止/取消、stdin 关闭、锁屏信号和已有目标保护。
- Portal 协议验证授权拒绝、早到 Response、请求/会话 Close、会话撤回；真实 PipeWire 画面经 Unix FD 和 serial 进入编码器，WebM 可解码，停止/取消/撤回均释放资源。
- 真实 Sway Screenshot portal 交互选择 401×301 区域并生成 PNG。纯软件 headless 环境的录屏被 portal-wlr 拒绝（缺少 DMA-BUF 格式）；CI 仅对该已识别限制允许明确记录降级，不把它记成完整桌面录屏通过。默认不加 `--allow-headless-no-dmabuf` 时测试严格失败。
- GTK 实际按钮启动截图/录屏、停止保存、首帧预览、取消、模块撤权；管理页复制/收藏入口、保护隐藏；剪贴板复制原始 PNG 与文件 URI，媒体租约随所有权释放。
- Fcitx 实际宿主验证标题/来源搜索、复制意图、Return 打开管理、收藏保护、临时删除、旧修订及保护边界；普通输入、笔记和资源回归同时验证。
- macOS debug 构建及生产卡片/时长样例导出通过；四主题图片和视频卡片双端截图已生成。

- 完整 Release 构建及 58 项 CTest 通过（41.30 秒）；17 项源码安装/卸载测试通过。新增 helper 纳入管理清单，原有用户数据与捕获哨兵保留。
- 从全新构建目录、锁定 Rime 引擎生成 `fcitx5-rimes_1.1.5_arm64.deb`，再次通过全部 58 项测试（41.80 秒）。实际安装、重装、卸载及动态库依赖检查通过，词库、学习记录、笔记、附件、剪贴板库、捕获元数据和原始录屏哨兵均保留。首次全新构建发现并修复 Wayland 协议生成目录的并行时序问题。

日志位于 `.build/linux-parity-20261017/task16-*.log`。
