# Capsule 五模块宿主验证（2026-10-18）

对应 #162，前置 #151/#153/#159/#161。当前状态为实现与验收中；模块专属后端与最终像素验收未完成，因此不关闭任务。

## 实现

- 从 macOS 官方模块源码提取五模块身份、顺序、图标名、过滤和管理页尺寸；从原生 smoke 提取相同的三条示例笔记，避免截图数据各自漂移。官方包改动见 scholay/rimes-plugins#11。
- Fcitx 负责导航、过滤、精确目标投递与撤权；GTK 管理页编辑同一私有仓库。进入管理页及返回底栏都撤销输入目标。
- 扩展 Markdown 记录至笔记、图片、视频、PDF、技能与资源；保留未知 front matter；SHA-256 revision 强制比较后更新/删除，附件按内容哈希存储。密码明文不能通过此仓库写入。
- 列表与详情后台读取；单条原子记录读取不等待写锁。过滤后的卡片与 IPC 不携带完整正文。停用保留磁盘数据并撤销可见内容及复制意图。
- 普通笔记表单含标题、摘要、类型和正文。未保存草稿在保护态期间从控件清除并暂存于进程内；恢复时不自动保存。保存与插件授权变化在同一锁内排序，排队取消也会结束忙碌状态。

- 完整 Linux CMake 构建，42 项 CTest 全部通过。

- `RimesCapsuleModules`：五个预装包、模块过滤、中文查询/退格、稳定 UUID 选择、停用清除、管理页撤权、脱敏投影、200 条传输窗口、授权变更后旧任务拒绝。
- `capsule-manager-ui`：真实 GTK 控件保存、940×660 与 620×430 的子控件坐标、尺寸与调整、保护态草稿恢复、停用后的保存拒绝、外部编辑冲突；新建空白草稿不会被宿主刷新替换；400 条库跨传输窗口的 End/PageUp 导航保持列表焦点。GTK critical 视为失败。

- `rimes-capsule-respawn-e2e`：杀掉 UI 后保持单实例重连，不重放历史复制或 wl-copy。
