# Capsule 资源与文献验证（2026-10-18）

对应 #165，依赖五模块宿主、结构化笔记和桌面剪贴板。功能已实现，像素及真实桌面验收尚未全部完成，任务保持打开。

## 实现与边界

- 文献、文档、项目、Skills、其他分类，Markdown 元数据和未知字段保留，CAS 修订检查；旧 PDF/Skill 无需迁移，元数据缺失不推断事实。
- macOS 生产代码导出 28 个引用样例，覆盖四种文献、六种单条格式、Unicode、缺失字段及 URL/DOI 规则。原生业务逻辑未改，只增加隔离的导出/渲染入口。
- 文件路径逐段 `O_NOFOLLOW` 打开；拒绝链接、回退路径及特殊文件。目录只保存路径。显式附件导入按哈希保存，备份迁移后可恢复原字节和文件名，删除条目或卸载不删除附件。
- 独立 `rimes-capsule-preview` 使用系统 Poppler / GdkPixbuf；PDF 256 MiB、图片 32 MiB、文本 1 MiB 上限；只渲染 PDF 首页，图片最长边 1600 px，文本显示 16000 字。进程限制 1 GiB 虚拟内存、5 秒 CPU、8 秒墙钟时间，取消会清理进程组。
- 文件复制使用 URI MIME 和 GNOME/KDE 复制语义；返回键等待桌面确认后关闭。源码和管理页不模拟粘贴、不自动执行文件，不将文件路径作为普通正文投递。机密保护、模块撤权、重连和旧修订均阻止迟到复制。
- 管理页连接真实持久化、预览、引用复制、路径选择及附件导入；未保存草稿和附件选项在保护态后恢复，正文在隐藏时清除。

## 已验证

Ubuntu 24.04 arm64 Docker、GTK 3.24、Fcitx 5.1.7、librime 1.10、Poppler 24.02、Xvfb 和 Sway；macOS 原生 debug 构建。

- 完整 Release 构建和 52 项 CTest 通过。新增资源检查覆盖真实双页 PDF 首屏、PNG、文本截断、二进制、超大 PDF、缺失文件、符号链接/父目录/FIFO、目录不递归导入、Skill 预览、全文元数据搜索、CAS、附件及备份迁移。
- GTK 管理页验证元数据、引用和文件复制动作、实际保存/附件导入、保护隐藏及草稿恢复、并发修订冲突。真实 X11 控制器验证 URI 字节、复制标记、保护和包撤权。
- Fcitx 实际宿主验证文献作者搜索、按修订复制文件、Return 确认时序、双击管理、旧修订拒绝及保护；普通中文输入、笔记 2.7 MiB 分片复制和剪贴板历史既有回归一并通过。
- 13 项源码安装/卸载生命周期测试通过，新增预览程序归入安装清单，附件及引用格式偏好哨兵保留。使用锁定 Rime 引擎构建 `fcitx5-rimes_1.1.5_arm64.deb`，实际安装、重装、卸载、动态库依赖及所有用户数据哨兵均通过。随后修正宿主测试的有序等待，未改变包内功能。
- 原生 debug 构建与 28 个实际引用样例导出通过；四主题 940×660 / 2x 真实管理页对照已生成。
