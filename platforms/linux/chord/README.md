# Linux 并击扩展

在 **设置 → 插件 → 内置扩展** 中启用“并击”，然后打开 **并击 → 配置**，点击“设为当前输入方案”。停用扩展会回到之前的普通输入方案，并保留键位和学习进度。本轮仅支持普通输入；意识流输入及其并击联动按维护者要求暂缓。

飞耀的组键间隔默认 0.10 秒，可设为 0.02–0.50 秒。它按停顿结算物理按键批次，支持左右手跨批配对；两个普通单键不会被拼成一组和弦。焦点、输入方案、组合文本或插件授权变化会使待处理批次失效。呦呦音形的折梅、寒梅预设使用方案自己的物理按下/全部松开规则，不使用飞耀计时器。

## 键位方案

飞耀是只读模板，可以复制后编辑。呦呦音形的字词和码元由原生方案定义，不能复制成飞耀映射表。Linux 完整版包含两套原生预设所需的字典、Lua 和来源说明；Data Preview 包仍保留原来的 57 文件清单。

键位页支持新建、复制、删除、JSON 导入/导出、左右键区编辑、映射搜索和本地试打。导入会产生独立的方案 ID。完整音节和拼音片段分别保留各自的边界规则，输出可选全拼或自然码双拼。单份 JSON 上限 2 MiB，每个方案最多 4096 条映射；最多保存 128 份草稿。

**保存草稿不会改变输入法。** 点击“应用键位方案”后，输入法冻结当前快照、重新部署，并逐条验证实际 Rime 输出。原生预设也会验证公开的字词样例。验证通过后才保存生效快照；失败则恢复原部署文件和旧方案。正在使用导入方案库时，先切回内置方案库，再应用并击。部署期间输入法暂时透传按键，设置页显示部署状态。

本地试打和练习只捕获当前练习区域获得焦点时的按键。离开区域、切换页面或按 Escape 会停止，不会向其他应用注入文字。学习页使用已应用的方案；尚未应用的草稿不会改变题目或按键判断。连续正确三次表示掌握。呦呦音形暂不提供飞耀课程。

## 用户数据与卸载

数据根目录为 `${XDG_DATA_HOME:-$HOME/.local/share}/rimes`；测试可用 `RIMES_USER_DIR` 指定隔离目录。

| 路径 | 内容 |
| --- | --- |
| `chord-keymaps/<UUID>.json` | 自定义键位草稿 |
| `chord-keymaps/active-profile.json` | 独立的已应用快照 |
| `chord-keymaps/state.json` | 输入方案选择与恢复状态，不保存日常输入 |
| `learning/<schema>_progress.json` | 不含输入正文的练习次数、正确次数和掌握状态 |

目录和文件分别使用 `0700`、`0600` 权限。损坏的数据会保留并报告错误，避免覆盖；并发编辑会检查版本。`apt remove fcitx5-rimes` 和源码 `uninstall.sh` 都保留这些数据及用户词库。安装和卸载方法见 [完整 Linux 版说明](../ime/README.md)。

实际宿主检查见 [桌面验收](../../../docs/platforms/linux/acceptance.md#extensions)；双端界面和实际桌面验收继续由 [#179](https://github.com/scholay/xsime/issues/179) 跟踪。
